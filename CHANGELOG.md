# Changelog

## 0.2.0 — Industrial backend foundation
- Added richer backwards-compatible SolveResult metadata: success, runtime, message and diagnostics.
- Added unified Ramanujan facade and registry.
- Added SciPy-backed dense/sparse linear solves, LP, MILP, nonlinear roots, continuous minimisation, quadrature, IVP ODE and LSMR Tikhonov adapters.
- Added industrial backend tests and release-gate documentation.
- Retained v0.1.0 reference algorithms and examples.
